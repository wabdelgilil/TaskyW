# 05. منظومة المشاركة والصلاحيات والعمل الجماعي (Collaboration & Sharing Specifications)

## نظرة عامة على نموذج المشاركة المتقدم (Multi-Level Sharing Architecture)
يعتمد التطبيق نظام مشاركة هرمي ومرن يتناسب مع كافة سيناريوهات العمل (العمل الفردي، التعاون المؤقت، أو فرق العمل المؤسسية)، ويشمل:
1. **المشاركة على مستوى المجال (Area Sharing)**: مشاركة المجال بكافة مشاريعه ومهامه دفعة واحدة.
2. **المشاركة على مستوى المشروع (Project Sharing)**: مشاركة مشروع بعينه وكافة المهام التابعة له فقط.
3. **المشاركة على مستوى المهمة (Task Sharing)**: مشاركة مهمة واحدة فقط مع مهامها الفرعية.

## 1. نوعا المشاركة الأساسيان (Access Modes)

```
                       ┌────────────────────────────────────────┐
                       │      نطاقات المشاركة في Tasky 3.0      │
                       │    (مجال Area / مشروع Project / مهمة)    │
                       └───────────────────┬────────────────────┘
                                           │
                 ┌─────────────────────────┴─────────────────────────┐
                 ▼                                                   ▼
┌───────────────────────────────────┐               ┌───────────────────────────────────┐
│     1. مشاركة برابط عام خارجي      │               │     2. مشاركة مع مستخدمين بحساب   │
│     (بدون حساب - Public Link)     │               │     (Collaborators with Account)  │
├───────────────────────────────────┤               ├───────────────────────────────────┤
│ • الصلاحية: قراءة وعرض فقط         │               │ • الصلاحيات المتاحة:              │
│   (Read-Only View)                │               │   1. رؤية فقط (Viewer)            │
│ • بدون تسجيل دخول أو حساب          │               │   2. رؤية وتعديل (Editor)         │
│ • عبر رمز أمان فريد (Share Token)  │               │   3. تحكم كامل وحذف (Admin)       │
│ • صفحة ويب خفيفة وسريعة           │               │ • يتم تحديد الصلاحية أثناء الدعوة │
│ • لا يمكنه رؤية أي بيانات أخرى      │               │ • يظهر في واجهة التطبيق لديهم     │
└───────────────────────────────────┘               └───────────────────────────────────┘
```

### أ. المشاركة بدون حساب (Public Read-Only Links):
* **الهدف**: تمكين الطرف الآخر (عميل، استشاري، مورد، زميل عمل مؤقت) من متابعة التقدم دون إلزامه بإنشاء حساب.
* **طبيعة الصلاحية**: **رؤية فقط (View-Only / Read-Only)** بنسبة 100%؛ لا يمكنه تعديل الحالات، إضافة مهام، أو حذف أي بيانات.
* **مستويات الرابط العام**:
  1. **رابط عام للمهمة**: يعرض المهمة، تفاصيلها، تاريخ التسليم، وقائمة المهام الفرعية (Checklist) ونسب إنجازها.
  2. **رابط عام للمشروع**: يعرض لوحة المشروع أو جدول مهامه ومؤشرات الإنجاز العامة.
  3. **رابط عام للمجال**: صفحة مخصصة تستعرض مشاريع ومهام هذا المجال فقط.
* **الآلية الأمنية**:
  - يعتمد كل نطاق على `share_token` مشفر وفريد (Cryptographically Secure UUID / Hash).
  - يمكن للمالك في أي لحظة **تعطيل الرابط (Revoke Link)** أو تجديده لمنع الوصول مجدداً.

### ب. المشاركة مع شخص بحساب (Authenticated Collaborators):
* **الهدف**: العمل التشاركي الحقيقي مع أعضاء الفريق أو الشركاء عبر السحابة (Supabase Cloud).
* **تحديد الصلاحيات عند الدعوة (Permission Levels)**:
  عند قيام المالك بإدخال البريد الإلكتروني للشخص المراد مشاركته، يختار له إحدى الصلاحيات التالية بدقة:
  1. **صلاحية العرض فقط (`viewer`)**:
     - يستطيع استعراض المجال/المشروع/المهام داخل حسابه، وتلقي التحديثات الحية، ولكن دون صلاحية تعديل النصوص أو الحالات أو الحذف.
  2. **صلاحية الرؤية والتعديل (`editor`)**:
     - يستطيع تغيير حالة المهام (To-Do -> In Progress -> Done)، وتعديل الأوصاف، وإضافة مهام فرعية، وتحديث التواريخ.
     - **لا يستطيع حذف** المشروع أو المجال الأساسي.
  3. **صلاحية التحكم الكامل والحذف (`admin` / `manager`)**:
     - يملك صلاحية الرؤية، التعديل، إضافة المهام والمشاريع، وحذف المهام أو المشاريع الفرعية داخل النطاق المصرح له به.
     - يتم حفظ معرف من قام بالحذف أو التعديل في سجل النشاط (`audit_log`).

## 2. هيكل البيانات في السحابة (Database Schema for Sharing)

```sql
-- 1. جدول مشاركات المجالات والمشاريع والمهام (Entity Shares)
CREATE TABLE IF NOT EXISTS entity_shares (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    entity_type TEXT NOT NULL, -- 'area' | 'project' | 'task'
    entity_id UUID NOT NULL,   -- معرف المجال أو المشروع أو المهمة
    owner_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
    
    -- للمشاركة مع مستخدم محدد بحساب:
    collaborator_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
    collaborator_email TEXT,
    permission_level TEXT NOT NULL DEFAULT 'viewer', -- 'viewer' | 'editor' | 'admin'
    
    -- للمشاركة العامة برابط بدون حساب:
    is_public_link BOOLEAN NOT NULL DEFAULT FALSE,
    public_token TEXT UNIQUE,
    allow_subtasks_view BOOLEAN NOT NULL DEFAULT TRUE,
    
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    expires_at TIMESTAMPTZ, -- اختياري: تحديد تاريخ انتهاء لصلاحية الرابط
    deleted_at TIMESTAMPTZ
);

-- فهارس الأداء السحابية
CREATE INDEX IF NOT EXISTS idx_entity_shares_lookup ON entity_shares (entity_type, entity_id);
CREATE INDEX IF NOT EXISTS idx_entity_shares_collaborator ON entity_shares (collaborator_id);
CREATE INDEX IF NOT EXISTS idx_entity_shares_token ON entity_shares (public_token);
```

## 3. واجهة وتجربة المستخدم أثناء المشاركة (UI/UX Flow)

1. **نافذة المشاركة الموحدة (Universal Share Dialog)**:
   - متاحة بضغطة زر مشاركة (🔗/📤) في:
     - شريط تفاصيل المهمة (`TaskDetailDrawer`).
     - رأس صفحة تفاصيل المشروع (`ProjectDetailScreen`).
     - رأس صفحة تفاصيل المجال (`AreaDetailScreen`).
2. **علامتا تبويب داخل نافذة المشاركة**:
   - **التبويب الأول: رابط عام (بدون حساب)**:
     - زر "تفعيل الرابط العام".
     - عرض الرابط القابل للنسخ بنقرة زر (`Copy Link`).
     - توضيح: *"هذا الرابط يتيح لأي شخص الاطلاع على المحتوى فقط دون القدرة على التعديل أو الحذف"*.
     - زر لتعطيل الرابط في أي وقت.
   - **التبويب الثاني: مشاركة مع فريق العمل (بحساب)**:
     - حقل كتابة البريد الإلكتروني للمستخدم المدعو.
     - قائمة منسدلة لاختيار الصلاحية:
       - 👁️ **مشاهدة فقط (Viewer)**: رؤية ومتابعة فقط.
       - ✏️ **رؤية وتعديل (Editor)**: إمكانية تعديل الحالات والبيانات وإضافة مهام.
       - 🗑️ **تحكم كامل (Admin)**: رؤية وتعديل وحذف المهام والمشاريع.
     - جدول يعرض الأشخاص الذين لديهم وصول مع إمكانية تعديل صلاحية أي شخص أو إزالته فورياً.

# 01. المعمارية والتقنيات (Architecture & Tech Stack)

## 1. الفلسفة العامة (Architecture Philosophy)
يعتمد نظام **Tasky 3.0** على معمارية برمجية حديثة ونظيفة (**Clean Architecture**) تفصل بصرامة بين طبقات البيانات ومنطق الأعمال وواجهات المستخدم، مع الالتزام التام بمبدأ **Offline-First**:
1. **العمل المستقل دون إنترنت أولاً**: كافة العمليات (إنشاء، تعديل، حذف، ترتيب، بحث) تتم محلياً وبشكل فوري على جهاز المستخدم عبر قاعدة بيانات SQLite.
2. **الاستعداد التام للمزامنة السحابية (Cloud-Ready)**: تم تصميم نماذج البيانات ومسارات المعرفات (UUIDs) لتكون متوافقة 100% مع خادم Supabase السحابي.

---

## 2. المنظومة التقنية (Technology Stack)

### أ. إطار العمل (Core Framework)
* **Flutter (Dart 3.x)**:
  - منصة موحدة تتيح بناء كود مصدري واحد (Single Codebase) يعمل بنسبة 100% كبرنامج أصلي على:
    - **Windows Desktop**: أداء عالي وسرعة استجابة فورية بدون استهلاك موارد المتصفحات.
    - **Mobile (Android & iOS)**: تجربة مستخدم لمسية انسيابية مع دعم الإشعارات المحلية.
    - **Web**: إمكانية تشغيل لوحة التحكم عبر المتصفح أو استعراض الروابط العامة للمهام.

### ب. طبقة البيانات المحلية (Local Data Layer)
* **SQLite Database**:
  - استخدام مكتبة `drift` أو `sqflite_common_ffi` لدعم بيئة الويندوز والموبايل والويب.
  - دعم المعاملات الذرية (Transactions) لضمان سلامة البيانات ومنع فقدانها.
  - الحذف الهادئ (Soft Delete) عبر حقل `deleted_at` لضمان صحة المزامنة لاحقاً.

### ج. طبقة السحابة والمزامنة المستقبلية (Future Cloud & Sync Layer)
* **Supabase (PostgreSQL Backend)**:
  - إدارة الحسابات والمصادقة (Supabase Auth).
  - المزامنة في الخلفية (Background Sync Queue) وتتبع الحالات عبر حقول `sync_status` و `updated_at`.
  - قواعد أمان صارمة (Row Level Security - RLS) لحماية بيانات المستخدمين وضمان خصوصية المهام المشتركة.

### د. إدارة الحالة وهيكلة المشروع (State Management & Clean Architecture)
* تطبيق نمط **Feature-First Clean Architecture**:
  ```
  lib/
  ├── core/                 # الثيمات، الأدوات العامة، الثوابت، وقواعد البيانات
  │   ├── database/         # إعدادات SQLite والاتصال
  │   ├── theme/            # ألوان وثيمات التطبيق (Dark / Light)
  │   └── utils/            # دوال مساعدة ومنتقي الألوان والتنبيهات
  ├── features/             # الميزات والوحدات الوظيفية
  │   ├── areas/            # إدارة المجالات
  │   ├── projects/         # إدارة المشاريع
  │   ├── tasks/            # إدارة المهام والمهام الفرعية
  │   ├── search/           # محرك البحث المقيّد بالسياق
  │   └── settings/         # الإعدادات وتخصيص الواجهة
  └── main.dart             # نقطة انطلاق التطبيق
  ```

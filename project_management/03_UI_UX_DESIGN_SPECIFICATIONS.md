# 03. مواصفات واجهات وتجربة المستخدم (UI & UX Design Specifications)

## 1. الهيكل العام والتجاوب (Responsive Layout Architecture)

### أ. على أجهزة الكمبيوتر والشاشات العريضة (Desktop & Web)
يعتمد التطبيق على نظام الثلاثة أعمدة المتكاملة:
1. **القائمة الجانبية (Left Hierarchical Tree Sidebar)** (عرض 260px - 300px قابل للطي):
   - **قسم الفلاتر الذكية (Smart Filters)**:
     - ☀️ **اليوم (Today)**: المهام المجدولة لتاريخ اليوم مع عداد.
     - 📅 **القادمة (Upcoming)**: المهام المجدولة مستقبلاً.
     - ⏳ **المعلّقة (Waiting / Blocked)**: مهام متوقفة على طرف خارجي أو موافقة.
     - 🔥 **عاجل (Urgent)**: المهام ذات الأولوية القصوى.
   - **قسم شجرة المجالات والمشاريع (Areas & Projects Tree)**:
     - تفرع شجري تفاعلي: كل مجال أمامه سهم فتح/طي (`Expand/Collapse ▾/▸`).
     - عند فتح المجال، تظهر قائمة مشاريعه مع إيموجي ولون مخصص وشريط تقدم ونسبة إنجازه.
     - أزرار سريعة (`+`) لإضافة مشروع جديد داخل المجال مباشرة.
   - **قسم الأدوات والإعدادات**: مفتاح التبديل للوضع الليلي/النهاري، الإحصائيات، والإعدادات.
2. **مساحة العمل المركزية (Center Main Workspace)**:
   - رأس الصفحة (Header): شريط البحث المقيّد بالسياق + محول طرق العرض (Tabs):
     - `[ 📋 عرض القائمة List View ]`
     - `[ 📊 عرض لوحة الكانبان Kanban Board ]`
   - زر رئيسي عائم أو بارز لإضافة مهمة سريعة (`+ إضافة مهمة`).
3. **درج وصفحة التفاصيل المنزلقة (Right Detail Drawer)** (عرض 380px - 450px):
   - ينزلق بسلاسة من اليمين عند النقر على أي مهمة دون مغادرة الشاشة الحالية.

### ب. شريط التنقل السفلي الموحد (Unified Bottom Navigation Bar)
* متوفر في **الويب، الديسكتوب، والموبايل**.
* يتيح الوصول المباشر والسريع للأقسام الأساسية:
  - ☀️ اليوم (Today)
  - 📋 القوائم (Lists)
  - 📊 الكانبان (Kanban)
  - 📁 المشاريع والمجالات (Projects & Areas)
  - ⚙️ الإعدادات (Settings)

## 2. نظام التخصيص اللوني الكامل (Full Color Picker System)
يوفر التطبيق منتقي ألوان كامل يتيح للمستخدم تخصيص الهوية البصرية:
* **تلوين المجال (Area Color)**: لتمييز المجال في القوائم والشجرة والرسوم البيانية.
* **تلوين المشروع (Project Color)**: ينعكس على كروت المشروع وشريط تقدمه.
* **تلوين المهمة (Task Color)**: خيار فريد يتيح للمستخدم إعطاء كارت المهمة إطاراً أو خلفية ملونة لتمييزها بصرياً فوراً (مثلاً: تنبيه لوني لمهام معينة).

## 3. صفحات التفاصيل والإدارة المتكاملة (Dedicated Detail Pages)

### أ. صفحة تفاصيل وإدارة المهمة (Task Detail Page / Drawer)
* تعديل العنوان الفوري بنقرة واحدة (Inline Edit).
* الوصف والملاحظات الغنية (Rich Text / Markdown) لتدوين تفاصيل فنية وملاحظات.
* محددات سريعة: الحالة، الأولوية، واللون المخصص.
* تاريخ التسليم ووقت الديدلاين مع زر جدولة التذكير المحلي.
* نقل المهمة بين المشاريع أو المجالات بنقرة واحدة.
* قائمة المهام الفرعية (Subtasks Checklist) مع شريط نسبة الإنجاز وزر إضافة سريعة.
* زر توليد رابط المشاركة وزر الحذف أو الأرشفة.

### ب. صفحة تفاصيل وإدارة المشروع (Project Detail Page)
* هيدر المشروع: الاسم، الوصف، الإيموجي، اللون، والحالة (نشط، متوقف، مكتمل)، وتاريخ التسليم.
* لوحة مؤشرات المشروع (KPIs): نسبة الإنجاز، عدد المهام المكتملة والمتبقية.
* قائمة المهام التابعة للمشروع مع دعم كامل للفلترة والتبديل لعرض الكانبان الخاص بالمشروع.
* زر إضافة مهمة مباشرة للمشروع.

### ج. صفحة تفاصيل وإدارة المجال (Area Detail Page)
* بيانات وهوية المجال (الاسم، اللون، الأيقونة/الإيموجي).
* إحصائيات عامة للمجال (مجموع المشاريع، إجمالي المهام، نسبة التقدم).
* بطاقات المشاريع التابعة للمجال مع زر إضافة مشروع جديد.
* قائمة المهام العامة المستقلة التابعة للمجال مباشرة (دون مشروع).
